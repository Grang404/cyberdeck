## Custom Cyberware
*Things you may want to change*

- **zsh vi mode:** `bindkey -v` in `$CYBERDOTS/zshrc` enables vim motions. `y`/`p`
in normal mode are synced to the Wayland clipboard (`wl-clipboard`). Remove
`bindkey -v` to revert to emacs-style editing.
- **Hyprland Keybinds:** Unusual keybinds present in Hyprland config, defined in
`$CYBERDOTS/hypr/keybinds.lua`. `SUPER + X` shows a search-able keybindings
menu.
- **Neovim:** minimalistic and heavily personalised. If you want more featureful setup, consider [LazyVim](https://www.lazyvim.org/) instead.
